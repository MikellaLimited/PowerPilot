PowerPilot 0.6.7 — temperature provider manager & condition animation isolation

Исправлено и изменено:
1. Переработана анимация «Дополнительных условий»: полный layout окна больше не выполняется на каждом кадре. Во время движения меняется только геометрия каталога условий и связанных с ним элементов; нативные поля скрываются один раз и возвращаются после финального кадра.
2. Удалён глобальный off-screen GDI-композитор 0.6.6, который добавлял лишнее копирование полного кадра и мог давать ощущение задержки. PowerPilot снова рисует напрямую через Direct2D; локальная анимация условий больше не трогает остальные вкладки.
3. Управление температурными датчиками перенесено в «Настройки → Данные». В мониторе ресурсов больше нет кнопки установки/обновления провайдера.
4. До установки температурного провайдера PowerPilot вообще не показывает температуры — ни ACPI, ни NVML/NVAPI, ни прочие fallback-значения.
5. «Установить датчики температур» теперь устанавливает полный официальный LibreHardwareMonitor-пакет, а не только DLL, и создаёт отдельный повышенный sensor-collector. Коллектор запускается через задачу Windows с повышенными правами и публикует полный список доступных температурных сенсоров в PowerPilot.
6. Повышенный sensor-collector опрашивает Hardware + SubHardware рекурсивно и собирает все SensorType.Temperature: CPU cores/package, GPU, NVMe/SSD, motherboard/Super I/O/EC/VRM и другие значения, которые реально предоставляет LibreHardwareMonitor на конкретном ПК.
7. После установки/обновления датчиков перезагрузка Windows не требуется: коллектор запускается сразу.
8. Добавлена настройка «Проверять обновления датчиков при запуске PowerPilot». Она включена по умолчанию и работает в том числе при запуске PowerPilot через автозагрузку.
9. Проверка обновлений не устанавливает ничего автоматически: при обнаружении новой версии карточка в «Настройки → Данные» меняется на «Обновить датчики температур»; установка запускается только пользователем и может запросить UAC.
10. Версия установленного провайдера хранится в HardwareProvider/version.txt; старые установки 0.6.6 без version.txt распознаются как v0.9.6.
11. При удалении PowerPilot удаляется задача «PowerPilot Hardware Sensors»; сам HardwareProvider удаляется вместе с настройками, если пользователь подтверждает удаление данных приложения.
12. Версия приложения и установщика обновлена до 0.6.7.

Техническое замечание:
Полнота списка температур зависит от поддержки конкретной материнской платы/EC/CPU самим LibreHardwareMonitor. Повышенный коллектор устраняет ограничение прав доступа, но не может создать датчик, который сам hardware provider не поддерживает.
