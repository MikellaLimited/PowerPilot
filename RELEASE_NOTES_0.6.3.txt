PowerPilot 0.6.3 — smoother condition catalog, action-editor fix and temperature monitoring

Исправлено и улучшено:
1. Переработана анимация «Дополнительных условий»: линейный прогресс + плавная геометрическая easing-кривая, один layout-pass на кадр и отсутствие постоянной перерисовки native EDIT при движении. Это убирает прежнее мигание и рывки при раскрытии/сворачивании.
2. Редактор действий уплотнён по вертикали: типы действий размещаются в двух рядах, блоки «При ошибке» и «Пауза после» подняты выше, а нижняя панель «Сохранить / Отмена» получила собственную поверхность. Служебные элементы больше не должны просачиваться за кнопки на минимальном размере окна/высоком DPI.
3. В «Ресурсы» добавлена средняя температура к основным показателям CPU, GPU и накопителей. Температура показывается рядом с основным значением слева в карточке.
4. В «Ресурсы → ⋮ → Продвинутый монитор» добавлена отдельная вкладка «Температуры». Она показывает все обнаруженные температурные датчики: устройство, датчик, текущую температуру и источник данных.
5. Температурный монитор использует цепочку доступных источников: LibreHardwareMonitor WMI (если провайдер доступен), ACPI thermal zones, Windows Storage Reliability для накопителей и NVIDIA NVML для видеокарт. Сбор выполняется асинхронно и не блокирует интерфейс.
6. Фоновый PowerShell-запрос температур запускается скрыто, без вспышки консольного окна.
7. Версия приложения и установщика обновлена до 0.6.3.

Release build: Windows x64, stripped (-s -w -trimpath).
