PowerPilot 0.6.0 — Ресурсы, продвинутый монитор и статистика

Главное
- Модуль «Монитор» переименован в «Ресурсы».
- Кнопка «Ресурсы» открывает обычный монитор, а отдельное ⋮-меню содержит «Продвинутый монитор» и «Статистика за период».
- Кнопка «Задача» открывает текущую задачу, а ⋮-меню содержит «Создать задачу» и «Сохранённые задачи».

Ресурсы — обычный монитор
- CPU, GPU, VRAM, RAM, диски, сеть и питание остаются в быстром обзоре с живыми графиками.
- Для дисков перечисляются все доступные логические тома, пригодные для мониторинга; список не ограничен фиксированным количеством кнопок.
- При выборе карточки «Диски» можно переключать конкретный диск/том и видеть его активность, свободное/общее место и отдельную историю.
- Кнопки дисков автоматически переносятся на новую строку, если не помещаются по ширине.
- Интервал обновления остаётся настраиваемым: 250 мс / 500 мс / 1 с / 2 с / 5 с.

Продвинутый монитор
- Отдельный экран со всеми обнаруженными процессами.
- По умолчанию системные процессы скрыты; существующая настройка «Отображать системные процессы» управляет их показом.
- Для каждого процесса отображаются CPU, GPU, рабочий набор RAM и дисковый I/O.
- Защищённые процессы, к которым Windows не даёт доступ к счётчикам, остаются в списке и показывают недоступные значения как «—», а не исчезают.
- Сортировка: CPU / GPU / RAM / Диск I/O / Имя.
- Список использует пиксельный скролл и scrollbar.

Статистика за период
- PowerPilot сохраняет отдельную историю ресурсов в %AppData%\\PowerPilot\\resource_stats.json.
- Периоды просмотра: 1 час / 6 часов / 24 часа / 7 дней / 30 дней.
- «Обзор»: среднее и максимум CPU, GPU, RAM, диска и сети + график истории.
- «По времени суток»: усреднение CPU/GPU/RAM по часам суток для выбранного периода.
- «Приложения»: среднее историческое потребление ресурсов отдельными приложениями — CPU, GPU, RAM и дисковый I/O.
- Статистика собирается раз в минуту и хранится до 30 дней.
- resource_stats.json теперь включается в резервную копию PowerPilot и восстанавливается вместе с настройками/историей.

Новые функции автоматизации из плана развития
1. CPU конкретного процесса — условие ≤/≥ N%.
2. GPU конкретного процесса — условие ≤/≥ N%.
3. RAM конкретного процесса — условие ≤/≥ N МБ.
4. Интернет — условие «подключён / отключён».
5. Полноэкранное приложение — условие «есть / нет».
6. Диск/устройство — условие «подключён / отключён» по букве диска или пути.
7. Приоритет процесса — новый шаг: Низкий / Обычный / Высокий.

Новые условия поддерживают существующие механики продвинутой задачи: И/ИЛИ, удержание, паузу после, тест и диагностику. Процесс для CPU/GPU/RAM и шага приоритета можно выбрать через общий безопасный picker процессов. Системные процессы в picker по-прежнему защищены существующими подтверждениями.

Надёжность и совместимость
- Старые числовые ID условий/шагов не изменены: новые типы добавлены в конец перечислений, поэтому задачи 0.5.x совместимы.
- Для недоступных процессных счётчиков условие не считается выполненным по ложному нулю.
- Исправлено сохранение выбранного приоритета процесса в редакторе шага.
- Каталог условий уплотнён до 5 колонок, чтобы новые блоки не раздували редактор на минимальном размере окна.

Сборка и проверка
- Windows x64, GUI build, -trimpath, stripped (-s -w).
- app / installer / uninstaller собираются через build_release.py.
- Payload PowerPilot.exe внутри Setup проверяется по SHA-256 на совпадение с standalone-сборкой.
- У финального Setup.exe автоматически проверяется RT_GROUP_ICON → RT_ICON (16/24/32/48/64/128/256 px, planes=1, 32-bit) и совпадение 256px-кадра с исходной иконкой.
- Визуальная проверка именно иконки файла Setup.exe в Windows Explorer остаётся обязательным ручным пунктом и не может быть выполнена в текущей Linux-среде.
