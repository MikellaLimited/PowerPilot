PowerPilot 0.6.1 — UX, редактор условий и статистика ресурсов

Задачи и планирование
- Навигация «Задача» и её ⋮ объединена в один split-button; то же сделано для «Ресурсы».
- При каждом запуске PowerPilot текущая «Дата и время» инициализируется текущими датой/временем и остаётся неизменной в рамках сессии, пока пользователь её не отредактирует.
- Простой текущей/сохранённой задачи теперь задаётся в секундах. При первом запуске 0.6.1 старые значения простоя из 0.6.0 автоматически переводятся из минут в секунды, чтобы смысл старых задач не изменился.
- Для выбора одного процесса добавлены компактные кнопки × для сброса выбора.
- В расписании переключатель автозапуска перенесён под дни недели, чтобы не выходить за границы; дни недели используют общий hover-акцент PowerPilot.

Продвинутые условия
- Основные условия всегда видны: CPU, GPU, Сеть, Диск, завершение файла и процесса.
- Остальные условия находятся под «Дополнительные условия ↓/↑».
- Процентные поля подписывают единицы: «Порог, %»; сеть/RAM/диск используют собственные единицы.
- «Удерживать» заменено на более ясное «Непрерывно, сек» / «Непрерывно / стабильно, сек».
- Управление скобками переименовано в «Открывающих скобок» / «Закрывающих скобок»; добавлена подсказка, что вводить скобки вручную не нужно.
- Футер редактора условий/шагов больше не участвует в анимационном смещении, поэтому визуальные кнопки «Сохранить/Отмена» совпадают с hitbox.
- Компоновка раскрытого каталога условий уплотнена, чтобы служебные поля не заходили на нижние кнопки.
- Вставленное условие/шаг сразу перестраивает геометрию блок-схемы и отображается без повторного входа во вкладку.

Шаги сценария
- Отдельный пункт Mute убран из списка типов шагов. Выключение/включение звука находится внутри шага «Громкость» рядом с режимом «Задать %».
- Legacy-сценарии с прежним Mute продолжают работать.

Блок-схема
- Undo/Redo визуально неактивны, когда отменять/повторять нечего; в редакторе сохранённой задачи они намеренно отключены, чтобы не менять текущую несвязанную задачу.
- «Просмотр» имеет ровно ту же суммарную ширину, что Undo+Redo.
- «Триггер И/ИЛИ условия» переименован в «Триггер + условия: И/ИЛИ».
- Узел «Когда» опущен ниже второй строки инструментов, чтобы не пересекаться с «Просмотр».

Сохранение и редактирование
- На странице сохранения нижняя подсказка показывает только тип: «Простая» или «Продвинутая».
- Продвинутая сохранённая задача по «Редактировать» сразу открывается в блок-схеме.
- На основной странице такого редактирования нет кнопки «Назад»; снизу находятся поле названия, «Сохранить», «Отмена» с подтверждением и «Проверка».
- «Проверка» сохранённой продвинутой задачи использует её изолированный черновик; тест/диагностика возвращаются обратно в редактор.

Ресурсы — продвинутый монитор
- Порядок колонок: Имя → CPU → GPU → RAM → Диск → Сеть.
- Заголовки колонок являются сортировками. Первый клик по новой колонке — по убыванию; повторный — по возрастанию; отображаются стрелки ↓/↑.
- Добавлена настройка «Скрывать процессы без обнаруженного потребления ресурсов».
- Колонки рассчитываются от доступной ширины, чтобы строки не выходили за рамку.
- Для процессов добавлен best-effort показатель «Сеть» на основе доступного Windows per-process Other I/O counter. Он полезен как оценка сетевой/прочей передачи, но не является точным ETW-счётчиком чистого интернет-трафика.

Ресурсы — статистика
- В «Обзоре» добавлены режимы графика: Общий, CPU, GPU, RAM, Диск, Сеть.
- Общий график показывает процентные метрики; сетевой график использует собственный динамический масштаб.
- GPU получил отдельный оранжевый цвет линии.
- В график «По времени суток» добавлена активность диска.
- В статистике приложений добавлены заголовки колонок: Приложение, CPU, GPU, RAM, Диск, Сеть, Трафик, Активность.
- Добавлено суммарное потребление трафика приложениями за выбранный период.
- Для приложений сохраняется приблизительное время активности по нахождению процесса на переднем плане в минутных статистических снимках.
- В ResourceStatSample сохраняется общий app traffic до ограничения списка top-приложений, чтобы итог не терял трафик процессов вне таблицы.

Настройки
- Интервал обновления ресурсов убран из общих настроек: он остаётся только непосредственно в модуле «Ресурсы».
- Исправлена формулировка защиты активности: «Не выполнять задачу, пока пользователь активен» + «Считать неактивным после N мин».
- Убрана лишняя подпись под «Отображать системные процессы».

Release build
- Windows x64, stripped (-s -w -trimpath).
- PowerPilot / Setup / Uninstall успешно прошли go test и финальную сборку.
- Setup icon: RT_GROUP_ICON → 7×RT_ICON, 16/24/32/48/64/128/256 px, planes=1, 32-bit; извлечённая 256px иконка совпадает с исходной.
- Визуальная проверка того, как сам Setup.exe отображается в Проводнике Windows, из Linux-среды невозможна и остаётся отдельным PENDING-пунктом релизного чек-листа.
