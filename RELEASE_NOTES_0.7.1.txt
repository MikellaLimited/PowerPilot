PowerPilot 0.7.1
================

Изменения:
- Убрана отдельная категория «Токи» и токовые (Current/A) сенсоры из интерфейса аппаратных датчиков.
- Проверка обновлений аппаратного провайдера теперь обязательная: выполняется при каждом запуске PowerPilot и повторяется каждые 3 часа, пока приложение работает.
- Переключатель авто-проверки в Настройки → Данные заменён на информационный блок с фиксированным расписанием проверки. Установка найденного обновления по-прежнему запускается вручную.
- В Продвинутый монитор → Датчики добавлено сворачивание компонентов. По умолчанию каждый компонент показан одной строкой; кнопка ▶/▼ раскрывает или скрывает его датчики.
- Группировка использует идентификаторы LibreHardwareMonitor, поэтому одинаковые по названию модули памяти/накопители не должны сливаться в один компонент.
- Прокрутка и расчёт высоты списка теперь учитывают только реально раскрытые строки датчиков.

Проверки релиза:
- go test: app / installer / uninstaller.
- Windows amd64 GUI release build.
- payload PowerPilot.exe внутри Setup совпадает со standalone.
- Финальный Setup.exe: техническая проверка RT_GROUP_ICON → RT_ICON, 16/24/32/48/64/128/256 px, planes=1, 32-bit, извлечённый 256 px кадр совпадает с исходной иконкой.
- Визуальная проверка именно иконки файла Setup.exe в Windows Explorer: PENDING (среда сборки Linux).
