PowerPilot 0.6.6 — flicker compositor & reliable temperature provider

Исправлено и улучшено:
1. Весь кадр PowerPilot теперь рендерится в off-screen memory DC и выводится в окно одним BitBlt. Это устраняет промежуточные кадры ID2D1DCRenderTarget, которые были видны именно при разворачивании/сворачивании «Дополнительных условий».
2. Анимация каталога дополнительных условий переведена на smootherstep по реальному времени. На время движения native EDIT-поля скрываются один раз, а геометрия считается из одного прогресса; после завершения выполняется один финальный layout.
3. Убран лишний промежуточный layout в момент нажатия на «Дополнительные условия», создававший ещё один визуальный кадр перед началом анимации.
4. В Продвинутый монитор → Температуры добавлен явный расширенный провайдер датчиков. Кнопка «Установить датчики» по запросу пользователя скачивает классический официальный LibreHardwareMonitor 0.9.6 с GitHub в приватную папку PowerPilot в LocalAppData.
5. PowerPilot ищет приватный LibreHardwareMonitor-провайдер раньше системных установок и перебирает все найденные DLL, а не прекращает попытку на первой несовместимой библиотеке.
6. Прямой LibreHardwareMonitor-проход теперь делает прогрев оборудования, короткую паузу и второй update перед чтением датчиков. Это важно для EC/материнской платы/части накопителей.
7. Таймаут полного Windows/LibreHardwareMonitor temperature probe увеличен до 16 секунд, чтобы медленная инициализация оборудования не обрезала часть датчиков.
8. В интерфейсе явно показано состояние расширенного провайдера. PowerPilot не скачивает его скрытно — установка запускается только по нажатию пользователя.
9. Версия приложения и установщика обновлена до 0.6.6.

Примечание по температурам:
Некоторые CPU/EC/материнские датчики требуют низкоуровневого провайдера и/или прав администратора. Встроенные Windows API не гарантируют доступ ко всем физическим сенсорам. PowerPilot 0.6.6 больше не маскирует это дополнительными fallback-значениями: для полного набора предлагается официальный LibreHardwareMonitor-провайдер.
