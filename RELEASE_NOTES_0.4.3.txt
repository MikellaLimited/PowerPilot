PowerPilot 0.4.3 — navigation & advanced-layout fixes

Исправлено и улучшено:
1. Исправлено наложение заголовка блок-схемы и кнопки логики триггера на узком окне. Заголовок больше не получает принудительную минимальную ширину, а панель продвинутой задачи стала компактнее.
2. В мини-режиме переставлены местами «свернуть» и «выйти из мини-режима»: порядок справа теперь 📌 → выйти из мини-режима → свернуть → закрыть.
3. В меню «Создать задачу» добавлен отдельный пункт «Из шаблона».
4. Кнопка «Шаблоны» удалена из продвинутой задачи и из редактора блок-схемы сохранённой продвинутой задачи. Шаблоны теперь являются именно способом создания новой задачи.
5. Поисковые поля в «Сохранённых задачах» и «Истории» сохраняют готовность к вводу при переключении раскладки клавиатуры (Alt+Shift / Win+Space).
6. Поиск в «Сохранённых задачах» больше не съезжает вниз при раскрытии меню «Задача»: выпадающее меню работает как overlay и не меняет layout страницы.
7. Дополнительно убран старый сброс геометрии подменю «Создать задачу» на странице дополнительных параметров простой задачи.

Проверки:
- Windows x64 cross-build: app / setup / uninstall — PASS.
- Static regression для заголовка блок-схемы на ширине 704 px — PASS.
- Payload Setup совпадает с standalone PowerPilot.exe — PASS.
- PE icon chain Setup.exe: 16/24/32/48/64/128/256 px, planes=1, 32-bit — PASS.
- Визуальная проверка именно иконки файла Setup.exe в настоящем Windows Explorer — требуется на Windows; Linux-среда не может выполнить этот пункт физически.
