PowerPilot 0.6.5 — condition catalog compositor & temperature fallbacks

Исправлено:
1. Анимация «Дополнительных условий» больше не запускает полный layout окна на каждом кадре. Это устраняет повторное скрытие/показ Win32 EDIT-контролов — основную причину мигания.
2. Нативные поля скрываются один раз на время раскрытия/сворачивания, а их значения временно рисуются в Direct2D-композиции и движутся вместе с остальным содержимым.
3. Геометрия редактора условий теперь сдвигается инкрементально; полный layout выполняется только один раз в конце анимации. Длительность полного эффекта увеличена до ~340 мс.
4. Для NVIDIA добавлен третий прямой источник температуры — NVAPI (nvapi64.dll), помимо NVML и nvidia-smi.
5. Таймаут nvidia-smi увеличен до 4 секунд, чтобы медленный первый запуск драйверной утилиты не отбрасывал показания.
6. Если полноценного CPU-сенсора нет, карточка CPU может использовать доступные Windows ACPI/Thermal Zone показания как явно ограниченный fallback; в расширенной таблице источник остаётся виден.
7. Приоритеты источников температур обновлены: NVML → NVAPI → nvidia-smi → LibreHardwareMonitor/OpenHardwareMonitor → Storage/ACPI.
8. Версия приложения и установщика обновлена до 0.6.5.

Примечание по температурам:
Полный набор CPU/Core/VRM/материнских датчиков на Windows нельзя гарантированно получить штатными API. Для таких сенсоров по-прежнему требуется поддерживаемый low-level provider/driver (например LibreHardwareMonitor + PawnIO) или vendor API. PowerPilot не подменяет отсутствующие показания выдуманными значениями.
